# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual Linear label strings used in this repo.

| Label in mattpocock/skills | Label in Linear | Meaning |
| -------------------------- | --------------- | ------- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

These labels exist in Linear for the `NEX` team. When a skill mentions a role, apply the corresponding label string via Linear MCP tools.
